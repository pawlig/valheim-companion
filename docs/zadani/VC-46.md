# VC-46 — hledání na rozcestníku: řádek otevře Items Compendium, ikonky „Open in …“

## Co chce Pavel (11. 10. 2026)
„Když vyhledávám item v searchi, chtěl bych vedle mít tlačítka — ikonky s tooltipem: otevřít v Compendiu, otevřít ve Smithy atd., abych si mohl vybrat. Když kliknu na celý řádek, bude to v Compendiu.“

## Dnešní stav
- Index: `scripts/build-search-index.mjs` → generuje `apps/hub/data/search.js` (`globalThis.VC_SEARCH_INDEX`). Každý záznam má jen jedno `url` (zbraň → `/smithy/#item=…`, jídlo → `/provisions/#item=…`, nábytek → `/comfort/#item=…`, surovina → `/items/#item=…`).
- Stejná věc je v indexu někdy 2× (např. „Cooked Boar Meat“ jako `material` i `food`).
- Vykreslení: `apps/hub/app.js` funkce `renderResults` (ř. ~68–220): každý výsledek je jeden `<a class="hub-search-item">`; klávesy ↑↓/Enter v `keydown` (ř. ~240–275) pracují s `.hub-search-item` a Enter volá `target.click()`.
- Items Compendium (`data/items-compendium.json`, pole `items[]`) má u položky `id` a `crossLinks` = `{ smithy?, provisions?, comfort?, traders? }` s hotovými URL.

## Rozhodnuté řešení (nic dalšího nevymýšlej)

### Krok 1 — data indexu (`scripts/build-search-index.mjs`)
Za všechny `index.push(…)` a **před** řazení (`index.sort`) přidej volání `attachCompendiumLinks` nad položkami kompendia a výsledek použij místo `index`. Vlep (uprav jen názvy proměnných, pokud se v souboru jmenují jinak; `DATA_DIR` v souboru existuje):

```js
// VC-46: rows point to the Items Compendium; every other tool that has the item becomes an action link.
const LINKED_TYPES = ['weapon', 'armor', 'food', 'material', 'comfort']; // also merge priority
const LINK_ORDER = ['items', 'smithy', 'provisions', 'comfort', 'traders'];

function attachCompendiumLinks(index, compendiumItems) {
  const byId = new Map(compendiumItems.map((item) => [item.id, item]));
  const merged = new Map();
  const result = [];
  for (const entry of index) {
    const hashId = entry.url.includes('#item=') ? decodeURIComponent(entry.url.split('#item=')[1]) : null;
    const comp = hashId && LINKED_TYPES.includes(entry.type) ? byId.get(hashId) : null;
    if (!comp) {
      result.push(entry);
      continue;
    }
    const urls = [`/items/#item=${encodeURIComponent(comp.id)}`, entry.url, ...Object.values(comp.crossLinks || {})];
    const previous = merged.get(comp.id);
    if (previous) {
      previous.links.push(...urls);
      if (LINKED_TYPES.indexOf(entry.type) < LINKED_TYPES.indexOf(previous.type)) {
        Object.assign(previous, { type: entry.type, image: entry.image || previous.image, biome: entry.biome, order: entry.order });
      }
      continue;
    }
    const row = { ...entry, url: urls[0], links: urls };
    merged.set(comp.id, row);
    result.push(row);
  }
  for (const row of merged.values()) {
    const byTool = new Map();
    for (const url of row.links) {
      const tool = url.split('/')[1];
      if (!byTool.has(tool)) byTool.set(tool, url); // first wins: the item's own link beats a set link
    }
    row.links = LINK_ORDER.filter((tool) => byTool.has(tool)).map((tool) => byTool.get(tool));
  }
  return result;
}
```

Načti kompendium: `JSON.parse(readFileSync(path.join(DATA_DIR, 'items-compendium.json'), 'utf8')).items` (když soubor chybí, `[]`). Záznamy bez kompendia (tvorové, sety zbrojí `#set=`, obchodníci, expedice) zůstanou, jak jsou — bez `links`. Klient pro ně použije `[item.url]`.

```js
    expedition: { label: 'Expedition', icon: '<path d="M5 21V4h11l-2 4 2 4H5"/>' },
  };

  function searchActionLink(url) {
    const tool = SEARCH_TOOLS[url.split('/')[1]];
    if (!tool) return null;
    const link = document.createElement('a');
    link.className = 'hub-search-action';
    link.href = url;
    const tip = t('Open in {tool}', { tool: tool.label });
    link.setAttribute('aria-label', tip);
    link.dataset.tip = tip;
    link.innerHTML = `<svg viewBox="0 0 24 24" width="18" height="18" fill="none" stroke="currentColor" stroke-width="1.8" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true">${tool.icon}</svg>`;
    return link;
  }
```

V `renderResults` nahraď stavbu výsledku (dnes `const a = document.createElement('a'); a.className = 'hub-search-item'; …; itemsDiv.appendChild(a);`) takto — obsah `a` (obrázek / placeholder / `infoDiv`) zůstává beze změny, jen se mění obal:

```js
          const row = document.createElement('div');
          row.className = 'hub-search-item';
          row.setAttribute('role', 'option');
          const a = document.createElement('a');
          a.className = 'hub-search-item-main';
          a.href = item.url;
          // … stávající kód, který do `a` přidává obrázek/placeholder a infoDiv …
          row.appendChild(a);
          const actions = document.createElement('div');
          actions.className = 'hub-search-actions';
          for (const url of item.links || [item.url]) {
            const link = searchActionLink(url);
            if (link) actions.appendChild(link);
          }
          row.appendChild(actions);
          row.addEventListener('click', (event) => {
            if (!event.target.closest('a')) a.click();
          });
          itemsDiv.appendChild(row);
```

V `keydown` u `Enter` nahraď `target.click();` za `(target.querySelector('.hub-search-item-main') || target).click();`. Výběr šipkami (`.hub-search-item`, třída `active`) nech.
